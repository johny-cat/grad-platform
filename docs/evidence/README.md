# Evidence for checked programs

One file per program, written when its details were checked: every fact in
`src/data/programs/<id>.json`, the official page it came from and the exact
sentence on that page that states it. Files starting with `_` hold a
university's central pages (graduate school deadlines, fees, English tests)
that several programs share.

They make a second check, and next season's re-check, fast: open the page,
find the sentence, compare. How to write them: `docs/CHECKING-PROGRAMS.md`.
Quotes are short and only as long as needed to show the fact.
